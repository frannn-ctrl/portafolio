Infraestructura de Sistemas Empresarial

En este proyecto se ha diseñado e implementado una infraestructura de sistemas para una pequeña empresa, simulando un entorno corporativo real mediante máquinas virtuales Windows y Linux. El laboratorio integra tecnologías de administración de sistemas, redes, monitorización y ciberseguridad con el objetivo de centralizar servicios, mejorar la supervisión de la infraestructura y automatizar la detección de incidencias.

La infraestructura está compuesta por un servidor Windows Server encargado de la administración del dominio y servicios de red, un servidor Ubuntu Server destinado al despliegue de servicios mediante Docker y herramientas de monitorización y seguridad, y un cliente Windows como equipo de usuario dentro de la empresa.

Se han configurado servicios como Active Directory, DHCP, DNS, IIS y hMailServer. Además, se han desplegado plataformas en contenedores Docker como GLPI y Wazuh.

GLPI se ha configurado como plataforma de gestión de incidencias y soporte técnico, integrada con Active Directory de Windows Server mediante LDAP para la gestión centralizada de usuarios.

En seguridad se ha implementado Wazuh (SIEM/XDR) para monitorización y análisis de eventos, junto con Suricata (IDS) para detección de tráfico sospechoso y análisis de red en tiempo real.

El proyecto busca recrear una infraestructura empresarial moderna, integrando administración centralizada, monitorización continua, análisis de eventos de seguridad y automatización de incidencias.
